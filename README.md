# ارتقاء - الإشراف

تطبيق ويب لمتابعة الحلقات والطلاب والنتائج الأسبوعية (الأسبوع 1–5) مع تصدير Excel.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد إلى الفرع `main`.
2. من **Settings → Pages** اختر **Deploy from a branch** ثم `main` و `/ (root)`.
3. بعد دقيقة يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`
4. افتح الرابط من الجوال في Chrome ثم اختر **تثبيت التطبيق / Add to Home screen**.

## ملاحظات
- البيانات تُحفظ في متصفح الجهاز (localStorage). استخدم **الإعدادات → حفظ نسخة احتياطية** بانتظام.
- مكتبة Excel (ExcelJS) تُحمَّل من cdnjs أول مرة ثم تُخزَّن للعمل دون إنترنت.
